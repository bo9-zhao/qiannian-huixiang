# 千年回响

## 使用
双击独立版 HTML 即可离线测试。source/index.html 也可直接打开，但需保留 js 文件夹。
20 道情境题、30 位人物、回退修改、六维解释报告、前三级匹配、结果文字/链接分享、打印保存报告、移动端自适应。无账号、无后端、无广告、不上传答案。

## 部署
将 source 内全部文件上传静态托管，index.html 位于网站根目录。GitHub Pages：新建仓库，上传 source 内文件；Settings → Pages → Deploy from a branch → main / root → Save。部署完成后访问 Pages 给出的 HTTPS 地址。也可上传到 Cloudflare Pages 的静态资源托管。无需构建命令。单文件独立版改名 index.html 也可部署。
本地预览：在 source 目录运行 python -m http.server 8080，然后访问 http://localhost:8080。
离线文件路径不能让朋友访问；离线时分享文字并发送 HTML，线上部署后分享链接可恢复六维结果。链接中只有分数，没有原始答案；接收者可以修改链接，所以结果不用于认证。

## 修改
js/questions.js：题干、选项及 scores；js/characters.js：人物、traits、介绍；js/app.js：算法和界面；index.html：配色和布局。当前 UI 自动读取题目数量，不要删除上游导出到 window 的语句。
算法：每维选项得分求和，除以该维逐题最高分之和，乘100；与人物六维向量计算均方根距离，按升序排序，同分按人物 ID 排。所有维度等权。没有常模，不将距离解读为真实人格概率。人物值和题目权重是编辑性设定，文化介绍沿用上游，未经史料逐项验证。
